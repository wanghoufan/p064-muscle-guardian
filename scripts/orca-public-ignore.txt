# ORCA 治理块｜公开仓不收录清单（母版托管单一真源，勿手改）
#
# 用途：注入到各项目根 .gitignore 的「ORCA 治理块」，让公开作品仓不收录 ORCA 通用脚手架，
#       但保留本项目自己的过程文档（计划/评审/交接/账本/经验），作为云端备份。
#
# 边界＝A1（只隐藏通用框架，保留本项目历史）：
#   - 本清单列出的＝每个项目都一样的**通用脚手架** → 隐藏
#   - 未列出的项目自有文档（PRODUCT_PLAN_*.md / BUGS-*.md / HANDOFF.md /
#     docs/model/*.jsonl / 经验一句话.md / 应用 README.md 等）→ **保留在公开仓**，作备份
#
# 重要：只写「已提交的 ORCA 脚手架」；应用自己的 README.md / README.en.md 绝不在此列
#       （那是作品首页，必须保留）。
#
# 维护：改动此文件＝改动所有项目的忽略块；改完请跑
#       bash scripts/check-sync.sh 确认两包一致，并重新对目标仓执行
#       bash scripts/orca-gitignore.sh <项目根> --untrack
