## 二、发现与处置

| ID | 现象 | 处置 |
|---|---|---|
| BUG-001 | 设置面板主题三按钮点击不生效 | 已定位并修复：`setMode` 引用不稳定导致 hydrate effect 反复重跑，把刚改的偏好回滚为持久化旧值；改为 `useCallback` ＋ 加载只跑一次。Web QA 三态＋刷新持久化复测 PASS |
| BUG-002 | manifest `short_name` 与 apple 标题带 `.pwa` 后缀（桌面图标名会显示「肌肉守护者.pwa」） | 已修为「肌肉守护者」，重建产物已核对 |
| BUG-003 | 移动端长按会弹 Chrome 文本选择菜单（截图为证） | 已加全局 `user-select:none` / `-webkit-touch-callout:none` 兜底；需用户在真机长按复核 |
