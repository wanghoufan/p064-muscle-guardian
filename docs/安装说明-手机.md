# 手机安装说明（小米 / OPPO 自带浏览器）

> 目标：把「肌肉守护者」放到桌面，像 App 一样点开；装好之后**断网也能用**，语音离线也在。

## 一、安装（约 1 分钟，用小米自带浏览器）

1. 打开**小米自带浏览器**（不是 Chrome），地址栏输入：
   `https://p064-muscle-guardian.pages.dev/`
   （GitHub Pages 那个 `wanghoufan.github.io/p064-muscle-guardian/` 地址小米浏览器**加不了桌面**，别用）
2. 等出现「肌肉守护者 / 每天蹲一会儿，腿更稳」。
3. 点底部 **三横 ≡**（菜单）→ 第 4 行 **「添加到桌面」**（不是灰的才行）。
4. 桌面出现绿色图标即完成。

> 打不开就先换 Wi-Fi/流量再试一次；GitHub 的地址在国内时通时不通，装好之后不受影响。

### OPPO 手机（ColorOS，2026-10-31 真机实测）

OPPO 自带浏览器**页面菜单里没有**「添加到桌面」，入口在书签里：

1. 用 **OPPO 自带浏览器**打开 `https://p064-muscle-guardian.pages.dev/`，等页面出现。
2. 点底部「工具栏」→ **书签收藏**（还没收藏就先在菜单里点「收藏」）。
3. **长按**「肌肉守护者」这条书签 → **「添加至桌面」** → 点 **「添加」**。
4. 桌面出现 1×1 的「肌肉守护者」即完成。

> 若长按菜单里「添加至桌面」是灰的：设置 → 应用 → 应用管理 → 浏览器 → 权限 → 打开 **「创建桌面快捷方式」**。

> ⚠️ 这个入口加的是**书签快捷方式**，点开仍走浏览器（带地址栏），不是全屏独立 App——OPPO 自带浏览器不支持 PWA 安装。要全屏独立 App 请装 APK（GitHub Release `v0.1.0` 的 `muscle-guardian-v0.1.0.apk`，或本机 `android-apk/肌肉守护者.apk`）。

## 二、打开后先验两件事

1. 点一个档位（如 **1 分钟**）→ 应听到「三、二、一、开始」。
2. 训练中每到整分钟会报「还剩 N 分钟」，结束时报「恭喜你完成训练」。

## 三、日常用法

- 点档位（1–10 分钟）**点一下就开练**，不用再点开始。
- 自由计时：点「开始自由计时」，想停就点「结束」。
- 练完会问「这次练完了吗？」：练完点 **「算数」**，中途放弃点 **「不算」**。
- 底部：**训练 / 测试 / 统计**。

## 四、常见问题

| 情况 | 怎么办 |
|---|---|
| 没声音 | 先确认**手机侧边音量键**不是静音；本项目语音是随包音频，不需要装语音包 |
| 打不开、白屏 | 换网络重试；装好的图标从桌面点开，通常走缓存能开 |
| 想更新 | 保持联网打开一次即自动更新 |
| 换手机 | 新手机按「一、安装」再走一遍，记录不跟随（数据只存本机） |
