# 手机安装说明（Android / Chrome）

> 目标：把「肌肉守护者」放到手机桌面，像普通 App 一样点开。装好之后**断网也能用**。

## 一、安装（约 30 秒）

1. 打开 Chrome，地址栏输入（或点这个链接）：
   `https://wanghoufan.github.io/p064-muscle-guardian/`
2. 等页面出现「肌肉守护者 / 每天蹲一会儿，腿更稳」。
3. 点右上角 **三个点 ⋮**。
4. 菜单往下滑，点 **「安装并创建快捷方式」**。
5. 弹窗点 **「安装」**。桌面就多了一个绿色图标。

> 找不到这一项？说明菜单没滑到底，继续往下滑；或先在页面上点一下再开菜单。

## 二、第一次打开要做的两件事

1. 点一次 **「设置」→「深色 / 浅色」**，看颜色是否变（验证装对了）。
2. 点 **「1 分钟」**，听是否有中文报「还剩 1 分钟」。

## 三、日常用法

- 想练多久就点几档：点 **「3 分钟」** 就直接开始，不用再点开始。
- 练完会问 **「这次练完了吗」**：练完了点 **「算数」**，中途放弃点 **「不算」**。
- 底部三个标签：**训练 / 测试 / 统计**。

## 四、常见问题

| 情况 | 怎么办 |
|---|---|
| 打不开、一直白屏 | 换 Wi-Fi 或流量再试（GitHub Pages 在国内时通时不通）；装好后不受影响 |
| 没有声音 | 手机「设置 → 更多设置 → 无障碍 → 文字转语音」里把引擎设为「小米语音引擎」，装一次中文语音包 |
| 页面被长按选中文字 | 已修，若仍出现，点「取消」即可 |
| 想更新到新版 | 打开一次 App（保持联网）即自动更新；或下拉刷新 |
