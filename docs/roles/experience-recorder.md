# experience-recorder（经验，一句话｜**编排者自做，不派工**）

> **2026-10-17 用户令：experience-recorder 不再作为独立派工角色，由编排者（task-manager）在收尾时自己做。**
> 本卡保留作**口径说明**（何时触发、写哪、达到什么标准），不再指派执行者、不占模型行、不进通道目录、不造 DISPATCH 派工行。
> 起因：表内原模型 `opencode/muse-spark-1.3-contributor-free` 已不在 opencode 通道目录（`check-channel-preflight.sh` 报 STALE 致预检长期红灯），
> 而该角色只是收尾时往 `经验一句话.md` 追加一句，另派一个角色的成本高于收益。
> 对照：`neat-freak` 同样已于 2026-10-16 改为编排者自做。

- 职责：收工时记一句“下次别踩”。
- 触发时机：收尾阶段（与 neat-freak 同一轮）。
- 执行者：**编排者本人**（不派工、不记 DISPATCH 行）。
- 输出：只追加到根目录 `经验一句话.md`（**追加，不改写已有条目**）。
- 标准：只写可复用的经验（判断口径、踩过的坑、修过的机制），**不写流水账、不写本次任务过程、不写模型或 token 数字**。
