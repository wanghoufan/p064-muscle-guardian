## 审查交付约定

当用户要求审查本项目、评估方案或给出审查意见时，审查者必须一次性交付完整结果，不得只列问题后停下。每次审查至少包括：

1. 明确的审查结论与是否建议通过；
2. 按优先级排序的问题、证据、影响和具体修订建议；
3. 对待拍板事项给出倾向、理由及主要风险，不把建议写成用户已决定；
4. 一份可直接转送开发者/智能体执行的完整提示词（目标、范围、约束、验收标准、交付要求）。
