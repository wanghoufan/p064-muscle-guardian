# PRODUCT_PLAN｜肌肉守护者（深蹲训练 PWA）V1.1

- Plan Version：V1.1（2026-10-30，按用户第二轮意见改版；见文末变更记录）
- PROJECT_PHASE：PLAN
- 交付形态：PWA（Android 为主，桌面浏览器可用）
- 代码基线：全新空项目（已铺 ORCA 治理包，无业务代码）

## 1. Product Goal

让爸爸（60 岁以上、独自在家练）能**一键开始一次有时长上限、有中文语音口令的深蹲训练**，练完自动留下记录，并能一屏看到「今天练了多久、这周练了几次、有没有进步」。

## 2. Target Users

- 主要用户：爸爸，60–70 岁，中老年，视力与听力有下降，手机操作不熟练，习惯单手拿手机、只看大字。
- 次要用户：家属（子女）帮他装 PWA、帮他看统计与测试成绩。

## 3. Problem

- 一个人练没有节奏：不知道练了多久、什么时候该停。
- 练完没有痕迹：一周后想不起来上次练了多少、有没有进步。
- 老人怕复杂：多一步跳转、小按钮、需要注册登录的 App，都会被放弃。
- 没有基线：不知道自己现在能蹲多久，训练强度全凭感觉。

## 4. Core Value

**一键开始 + 中文语音陪伴 + 一屏坚持情况**。全流程不注册、不联网、不弹广告，断网可用。

## 5. User Flow（每条都能逐项验收）

- **UF-1 倒计时训练（主路径）**：打开 App → 默认停在「训练」tab，顶部直接显示「今天 N 次 · M 分钟」→ 在「倒计时训练」区点一下 1/…/10 分钟某一档 → **立刻**听到「三、二、一、开始」（3 秒内可点「取消」）→ 大字剩余时间 → 每跨过一个剩余整分钟播报「还剩 N 分钟」→ 归零播报「恭喜你完成训练」→ 弹「这次练完了吗？」算数 / 不算 → 算数写入训练记录，首页与统计页今日数据立即更新。
- **UF-2 自由计时训练**：训练 tab 下方「自由计时」区点「开始自由计时」→ 立即进入正计时 → 每满一个整分钟播报「已练 N 分钟」→ 练到想停点「结束」→ 播报结束语 → 弹「这次练完了吗？」→ 算数：写入记录（精确到秒）／不算：丢弃。
- **UF-3 摸底测试**：点「测试」tab → 点「开始测试」→ 尽全力蹲到撑不住 → 点「结束测试」→ 弹「这次测试算满吗？」→ 算数：写入测试记录并更新本次/最好成绩与趋势；不算（中途被打断、走开）：丢弃，不入任何统计。
- **UF-4 看统计**：点「统计」tab → 顶部三张卡（今日练习时长 / 近 7 天 / 近 30 天）→ 7 天柱状图 → 30 天柱状图 → 下方按时间倒序的训练记录列表。
- **UF-5 看进步（测试）**：测试 tab 下方折线图，≥2 次测试时展示成绩趋势；1 次时提示「再测一次就能看到趋势」。
- **UF-6 设置**：任意 tab 右上角齿轮 → 主题（跟随系统/浅色/深色）、语音开关、安全提醒、关于（含版本号）、清空数据（两次确认）。

## 6. Functional Scope

- FR-01 底部三 tab：训练 / 测试 / 统计（顺序：左训练、中测试、右统计）。
- FR-02 训练页「倒计时训练」区：10 档 1–10 分钟，**点档位即刻开始**（无模式切换、无二次「开始」按钮）。
- FR-03 训练页下方「自由计时」区：独立卡片 + 一键开始，不放在倒计时区里，也不需要切换模式。
- FR-04 语音：开始播「三、二、一、开始」；倒计时每跨过一个剩余整分钟播「还剩 N 分钟」；自由计时每满一个整分钟播「已练 N 分钟」；结束播「恭喜你完成训练」（含本次时长）。
- FR-05 训练结束（含归零、手动结束）与**测试结束**一律弹确认：算数→写入并计入统计；不算→丢弃，不入任何统计。
- FR-06 计时中显示大字剩余时间 / 已用时间，并提供暂停 / 继续 / 结束。
- FR-07 计时基于真实时钟（wall clock），息屏、切后台、锁屏后回到前台不漂移；训练中请求屏幕常亮（Wake Lock，不支持时降级）。
- FR-08 语音失败（设备无中文语音 / 被系统静音）降级为提示音，并提示「本机语音不可用」，训练仍可正常完成。
- FR-09 测试 tab：开始 / 结束两态正计时；结束弹「算满 / 不算」确认后才写入测试记录并展示本次与最佳成绩。
- FR-10 测试 tab 展示成绩折线图与测试记录列表。
- FR-11 首页顶部显示**今日次数与今日时长**；统计 tab 三张卡：今日练习时长与次数、近 7 天合计、近 30 天合计。
- FR-12 统计 tab 7 天、30 天柱状图，**必须带纵坐标（分钟刻度）与横向刻度线**（照 053 护眼监测的柱状图口径），按本地日历天聚合。
- FR-13 统计 tab 历史训练记录列表（日期、时长、方式）。
- FR-14 全部数据本地持久化，刷新 / 重启 / 离线后仍在。
- FR-15 主题三态、语音开关、清空数据持久化。
- FR-16 PWA：可安装、离线打开、manifest 与 service worker 由构建脚本生成。
- FR-17 安全提醒（L2 展开）：量力而行、膝/腰疼痛立即停止、地面防滑。
- FR-18 记住上次选的时长档位，下次进入该档位高亮（老人少记一件事）。
- FR-19 「三二一」口令期间可点「取消」退出，不产生记录。

## 7. Out of Scope（V1 不做）

- 深蹲次数 / 组数计数、姿态识别、摄像头。
- 账号、云同步、多设备、多家庭成员。
- 推送提醒 / 日历 / 微信分享。
- 音乐库、训练计划编排、AI 教练。
- 原生 Android / iOS 安装包（仅 PWA）。
- 任何医疗诊断、康复处方类内容。

## 8. 核心任务与 MVP 边界（Gate A）

- **核心任务（一句话）**：一键开始一次有时长上限、有中文语音口令的深蹲训练，并在结束后确认是否完成。
- **高频功能**：①首页直接点时长档位开始 ②结束后点「算数」入账 ③首页看今日次数/时长。
- **MVP 必含**：三 tab、首页今日统计、10 档倒计时（点即开始）、自由计时独立区、开始/整分钟/结束语音、训练与测试都要完成确认、训练统计（三卡＋带纵坐标的两图＋列表）、测试成绩曲线、主题三态、PWA 安装与离线、安全提醒。
- **可延后 / 可隐藏 / 可取消清单**：
  - 可隐藏：独立设置页 → 先挂在右上角齿轮；「安全提醒」默认折叠（L2），不与主按钮抢位。
  - 可延后：数据导出（CSV/文本）、30 天按周聚合视图、测试目标值设定、最后 10 秒逐秒倒数。
  - 可取消：训练页的进度环、动画特效、历史记录筛选与搜索（记录量小，不需要）。
  - 明确不制造：无成就徽章、无连续打卡天数商业化、无引导流程（三步上手已足够）、无多语言切换。
- **交付形式判断**：PWA。理由：不需要应用商店与原生权限；老人手机点链接即可「添加到主屏幕」，迭代即时生效；离线可用满足无网场景；与 062 PWA 交付链路一致，复用成本最低。
- **治理强度分级**：
  - 安全风险＝中（运动有受伤风险，须有停止条件告知；不做医疗建议）
  - 设备能力＝中（语音、音频、屏幕常亮、离线缓存）
  - 数据敏感度＝低（仅本地时长/日期，无身份信息）
  - 异常恢复＝中（息屏/切后台/误触结束/数据丢失需可恢复）
  - 用户操作复杂度＝低（单主任务、单按钮主线）
  - 判定级别＝**标准**（不减安全告知、隐私与授权、数据正确性、异常与中断恢复、真机可用性五类验收）
- 本节自动生成的 AC：见 AC-27 ~ AC-31。

## 9. APP 基础能力声明

- 适用性：是，面向用户交付 APP（PWA）。
- 平台与技术栈：Expo 57 + React Native Web 0.21 + TypeScript；静态导出后由 `scripts/prepare-web.cjs` 生成 manifest 与 service worker。
- 主题：`LIGHT` / `DARK` / `SYSTEM`，默认 `SYSTEM`；计时页（沉浸式）**遵守用户所选主题，不强制任何一态**。
- 语言：**仅简体中文 `zh-CN`，不做英文**（用户 2026-10-30 明确要求：APP 只给爸爸用）。文案集中放 `src/i18n/strings.ts` 单一中文词典，不写散落硬编码，未来若要加语言只增资源即可。
- 设置持久化：主题、语音开关、上次时长档位重启保留；训练进行中切主题不丢计时状态。
- 可扩展架构：语言资源集中（`src/i18n/`），未来加 ru/ko/th 只增资源与必要适配；V1 不制作其它语言。
- 语音能力：是（语音类 APP）。中文 `zh-CN`；语速偏慢、音量固定；失败回退为提示音并可见提示。
- 技术栈复用判定（先查 062/047/025 已有依赖）：
  - 主题＝`REUSE`（复制 062 `src/theme/` 三态 Context ＋ 语义 Token）
  - 多语言＝`BUILD`（按用户要求不做英文：只建单一中文词典 `src/i18n/strings.ts`，不引入语言切换 UI）
  - 存储＝`ADAPT`（AsyncStorage + schema 版本 + 迁移，Web 落到 localStorage）
  - 计时＝`ADAPT`（047 `useMealTimer` 的墙钟 + 单调时钟校准思路，砍掉饮食相关状态）
  - 语音＝`ADAPT`（025 `expo-speech` → Web SpeechSynthesis，加降级）
  - 图表＝`BUILD`（053 是原生 Canvas 自绘，Web 端不通用；改为 Views 柱状 + SVG 折线，均自绘）
  - PWA＝`REUSE`（062 `scripts/prepare-web.cjs` ＋ `.github/workflows/pages.yml`）
- 覆盖记录：**语言覆盖**——用户 2026-10-30 明确「不做英文，这个给爸爸用」；仅保留 `zh-CN`，取消语言设置项与英文资源。主题三态仍按全局默认保留。

## 10. APP 品牌资产方向

- 命名方向：中文口语、好念、带一点守护感；英文直白、便于仓库与包名。
  - A 方案：中文「肌肉守护者」／英文 `MuscleKeeper`（与项目目录一致）
  - B 方案：中文「深蹲守护者」／英文 `SquatKeeper`（功能更直白）
  - C 方案：中文「蹲一蹲」／英文 `SquatDaily`（口语、更亲切）
- 图标风格偏好：几何线性（简化腿部/哑铃轮廓），单色主色 + 米白底，小尺寸仍可辨识；不做拟物插画。
- 启动画面要求：主色渐变底 + 中文名 + 副标题「陪爸妈练深蹲」，与浅/深两态兼容（深色下用深底）。
- 副标题 / slogan：需要，候选「每天蹲一会儿，腿更稳」。
- 资产交付形态：原型内提供三套图标方向色块草案 + 启动页示意；最终由 Design Freeze 出 192/512 PNG 与 apple-touch-icon。
- 最终拍板预留：名称、图标、启动画面、slogan 在 Human 2 前由用户拍板，未拍板前开发只用占位名。
- 桌面快捷方式名（遵循全局规则）：安装名「肌肉守护者.pwa」。

## 11. APP 界面信息分层声明

- L1 默认可见：剩余/已用时间、开始/结束/暂停按钮、时长档位、本次是否完成、今日与近 7 天时长、测试本次成绩。
- L2 主动展开：安全提醒全文、统计口径说明（「近 7 天含今天，按手机本地日期」）、记录明细、设置项说明。
- L3 不上屏：存储 key、schema 版本、AC/FR 编号、构建 hash、内部错误码（版本号仅出现在「关于」里，属可查信息）。
- 文案转换约定：内部完成状态 `FINISH_REASON_*` → 「练完 / 中途结束」；错误码 → 「语音不可用，已改用提示音」。
- 安全边界：不出现「治疗 / 康复 / 医嘱」措辞；安全提醒常驻可展开，不隐藏、不缩成一行小字；不记录任何健康诊断数据。

## 12. APP 导航与视觉方向声明

- APP 导航与视觉方向声明：已填写（底部导航采用；三方向 A/B/C 在训练页并置对比；入口/图标/四态/排版/显隐/适配见下）。
- 适用性：需要底部导航（三个并列任务：训练、测试、统计）。
- 是否采用底部导航：**采用**。理由：三类任务并列且都需高频进入；老人依赖固定位置记忆，比隐藏式菜单更稳。
- 视觉方向差异化轴（同一核心页＝训练页，三方向并置对比，原型可切换）：
  - A「大字极简」：单列流式布局、极低密度、超大数字、无卡片、留白最大；图标线性；调性安静克制。
  - B「卡片数据」（**用户 2026-10-30 选定**：因为首页就能看到今天练了几次、多少分钟）：卡片分层、圆角大、轻阴影；今日统计卡置顶；调性温和有条理。
  - C「高对比大按钮」：按钮占屏、时长用两列大格子、文字加粗高对比、几乎无留白；调性明确、像遥控器。
  - 三方向差异覆盖：布局结构、信息密度、字体层级、图标、组件造型、留白、品牌调性（非仅配色）。
- 最终视觉方向：**B 卡片数据**（A/C 仅保留在原型里作对照，不再迭代）。
- 导航入口：名称「训练 / 测试 / 统计」，数量 3，顺序左→中→右即训练→测试→统计。
- 导航图标：线性 24px（选中加粗为填充感），自绘 SVG，不引图标库。
- 导航状态：选中＝主色文字+图标＋主色浅底胶囊；未选中＝次级文字；点击＝底色加深 8%；焦点（键盘）＝2px 外描边。
- 排版：系统无衬线；数字用等比数字（tabular-nums）；标签 19px / 标题 23px / 计时数字 72–96px。
- 显示与隐藏条件：训练进行中进入沉浸态时底栏隐藏，只留「结束」；结束并确认后恢复底栏。
- 适配：小屏 360×640 不截断；**仅中文，无英文长文案场景**；底部按 safe-area 留白。
- Android 实现取向：PWA 以 RN Web 自绘底部导航（Material 3 视觉语义对齐），不引入导航库。

## 13. Technical Approach

1. **工程骨架**：照 062 结构（`App.tsx` ＋ `src/{components,domain,hooks,i18n,storage,theme,types}`），Expo 57、RN Web、TS、jest-expo。
2. **状态与计时**：`useSquatTimer`——`startedAt` 墙钟 + `performance.now()` 单调校准；500ms tick 只用于渲染，时长一律由时钟算（照 047）；`visibilitychange` 回前台立即重算；训练中调 `navigator.wakeLock.request('screen')`，`visibilitychange` 后重新申请，不支持则忽略。
3. **语音**：`src/services/speech.ts` 封装 `expo-speech`（Web 走 `SpeechSynthesis`），统一 `zh-CN`、`rate≈0.9`；首次播报绑定在「开始训练」点击手势内（满足浏览器手势要求）；`voices` 为空时降级 WebAudio 蜂鸣 + 界面提示；语音开关关闭时只保留蜂鸣。
4. **语音时序**：开始口令用「三 / 二 / 一 / 开始」四段独立播报，每段间隔 1s，与计时起点对齐（口令最后一段结束才计入训练时间）；倒计时最后 10 秒用短提示音报数（可关）。
5. **完成确认**：`Modal` 双按钮（是/否）；是 → 写 `training` 记录；否 → 丢弃，不入任何统计（与「只作为测试而已」一致，不写测试记录）。
6. **存储**：AsyncStorage，key `muscleKeeper:v1`，`{ version, trainings[], tests[], prefs }`；读取失败/损坏回退空库，不白屏（照 062 `storage.ts`）。
7. **统计聚合**：`domain/stats.ts`，按本地日历天 key（`YYYY-MM-DD`）分桶；`today / last7 / last30` 直接从记录过滤，不做缓存表。
8. **图表**：`components/charts/BarChart.tsx`（Views 定高柱＋基线＋日期标签，刻度取「整点值」）；`LineChart.tsx`（react-native-svg 折线＋点＋轴，Web/native 双端可用）；空数据画占位槽不画假数据。
9. **PWA 交付**：`npm run build` = `expo export --platform web` + `prepare-web.cjs`；manifest 主题色跟随主色、`display: standalone`、192/512/180 图标；SW 前缀 `muscle-keeper-`，预缓存剔除点文件（062 已踩坑）；GitHub Actions 发布 Pages。
10. **质量门**：`npm run typecheck` + `npm run lint` + jest 单测（domain 计时/聚合/确认逻辑）；真机（小米 Note11 5G）安装 PWA 实测语音、息屏、离线。

## 14. Data / API

- 本地 schema（`version: 1`）：
  - `trainings: { id, mode: 'countdown' | 'free', targetSeconds?: number, seconds: number, startedAt: ISO, endedAt: ISO, completed: true }[]`
  - `tests: { id, seconds: number, testedAt: ISO }[]`
  - `prefs: { themeMode: 'system'|'light'|'dark', localePref: 'system'|'zh'|'en', voiceEnabled: boolean, lastDurationMinutes: number }`
- 无服务端、无 API、无账号、无第三方上报；全部数据留在设备本地。

## 15. Key Assumptions

- A1 爸爸用 Android 手机（小米系），主用 Chrome / 系统浏览器，能「添加到主屏幕」。
- A2 设备自带中文 TTS 或可装 Google 语音；不能时降级方案可接受。
- A3 单设备、单用户，不跨设备同步；清空数据由用户确认后不可恢复（需二次确认）。
- A4 训练时长以秒为单位，误差目标 ≤1 秒 / 次。
- A5 屏幕常亮可用（Chrome Android 支持 Wake Lock），不支持时以语音＋大字弥补。

## 16. Competitor / Research Summary

- 计时类 App（Keep、番茄钟类）普遍把「选时长」藏进多级菜单、字体小、需要账号；对本项目**只借鉴单一大按钮＋倒计时大字的做法**，不借鉴训练计划体系。
- 老人可用性共识：单手可达、按钮 ≥48px、字号 ≥19px、状态变化要有声音反馈、错误要能撤销。
- 四个内部参考项目的可复用结论：
  - 047 正念吃饭：三 tab 自绘 TabBar、墙钟计时防漂移、Session 落库与「结束即写记录」的写法可直接照搬。
  - 025 拉伸语音播报：`expo-speech` 封装 + TtsService 注入 + 卸载清理，是本项目语音层模板。
  - 053 护眼监测：今日/7 天/30 天聚合口径与柱状图自绘（原生 Canvas 不可直接复用，口径可复用）。
  - 062 蛋白质 PWA：`prepare-web.cjs` 生成 manifest/SW、GitHub Pages 发布、主题/i18n/存储三件套，是交付骨架。

## 17. Risks

| 风险                             | 影响             | 应对                                                                                                |
| -------------------------------- | ---------------- | --------------------------------------------------------------------------------------------------- |
| Web 端中文 TTS 不可用 / 无声     | 核心语音卖点失效 | 开发首日做语音冒烟（Chrome Android + 小米浏览器）；失败降级蜂鸣＋大字＋震动（若可用）；语音开关可关 |

| 老人误清空数据                   | 不可逆           | 清空需两次确认 + 明示「记录会全部消失」                                                             |
